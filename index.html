How this prototype works

  1. Requests access to the device camera.
  2. Measures pixel differences between consecutive video frames.
  3. Converts the movement estimate into a score from 0–100.
  4. Shows Low, Medium, or High movement level and logs changes.
Safety limitation: Movement intensity alone cannot determine whether a patient is about to fall or has exited the bed. This prototype is for demonstration only and must not be used for clinical decisions or replace staff supervision.
Tip: Use Chrome or Edge on localhost/HTTPS. Camera access may be blocked when opening a file directly; if so, run a local web server in the folder with python -m http.server 8000 and open http://localhost:8000.
